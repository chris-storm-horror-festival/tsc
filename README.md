# TCS Productions — GitHub Pages

## Upload
1. Create a GitHub repository (z. B. `tcs-productions`).
2. Upload all files/folders from this package to the repository root.
3. GitHub → Settings → Pages → Deploy from branch → `main` / `(root)`.
4. Die Website ist dann unter `https://DEIN-USERNAME.github.io/tcs-productions/` erreichbar.

## Kontaktformular
Das Formular nutzt FormSubmit und sendet an `chrisstormfilms@gmail.com`. Beim ersten Einsatz kann FormSubmit eine Bestätigung des Empfängers verlangen.
